Capítulo 01 · 5 minutos

Deploy mais rápido: Netlify Drop

Sem cadastro demorado, sem terminal. Arraste e solte.

1

Descompacte o pacote

Extraia o arquivo nexvon-site.zip para uma pasta no seu computador. Você verá os arquivos: index.html, favicon.svg, README.md e arquivos de configuração.

2

Acesse o Netlify Drop

Abra https://app.netlify.com/drop no navegador. (Crie uma conta gratuita se for solicitado — leva 30 segundos com Google.)

app.netlify.com/drop
📁
Arraste sua pasta aqui
ou procure no computador
3

Arraste a pasta

Pegue a pasta nexvon-site (descompactada) e arraste para dentro da área pontilhada. O upload começa automaticamente.

▼ aguarde o upload ▼
4

Site no ar!

Em ~30 segundos você recebe um link: https://nome-aleatorio.netlify.app. Clique e seu sistema NEXVON estará funcionando com HTTPS.

✅ Deploy concluído! Seu site: https://nexvon-fluencia.netlify.app
Abrir site
💡 Dica: em Site settings → Change site name, personalize o endereço (ex: nexvon-fluencia.netlify.app). Para domínio próprio (ex: fluencia.seusite.com, vá em Domain settings → Add custom domain.

Capítulos 02 e 03 · 10 minutos

Vercel & GitHub Pages

Opção A — Vercel (via terminal)

1

Instale a ferramenta: abra o terminal e digite npm i -g vercel (requer Node.js instalado).

2

Entre na pasta do projeto: cd nexvon-site

3

Digite vercel e responda às perguntas (Enter para tudo padrão). Em ~20 segundos: https://seu-projeto.vercel.app

$ vercel
✅ Deployed → https://nexvon.vercel.app

Opção B — GitHub Pages (gratuito, sem terminal)

1

Crie uma conta no github.com e clique em New repository. Dê um nome (ex: nexvon) e marque Public.

2

Na página do repositório, clique em uploading an existing file e arraste todos os arquivos da pasta nexvon-site (incluindo os arquivos que começam com ponto: .htaccess, .nojekyll). Clique em Commit changes.

3

Vá em Settings → Pages. Em Branch selecione main e pasta / (root). Clique em Save.

Source: Deploy from a branch
Branch: main / (root) Save
4

Aguarde 1 minuto. Seu site estará em: https://seu-usuario.github.io/nexvon/

⚠️ No GitHub Pages, certifique-se de que o arquivo .nojekyll foi enviado — sem ele, o GitHub pode bloquear arquivos que começam com underline.

Capítulo 04 · Hospedagem tradicional

cPanel / FTP (HostGator, Locaweb, etc.)

1

Baixe o FileZilla

Programa gratuito de FTP: https://filezilla-project.org. Instale e abra.

2

Conecte ao seu servidor

No topo do FileZilla, preencha com os dados do seu provedor (encontrados no e-mail de boas-vindas da hospedagem):

Servidor: ftp.seusite.com · Usuário: seu_usuario · Senha: •••••• · Porta: 21
Conexão rápida
3

Envie os arquivos

No painel direito (servidor), entre na pasta public_html (ou www). No painel esquerdo (seu computador), entre na pasta nexvon-site. Selecione todos os arquivos e arraste para a direita. Aguarde o upload.

▼ arraste da esquerda para a direita ▼
4

Acesse seu domínio

Pronto! Acesse https://seusite.com — o index.html carrega automaticamente. O arquivo .htaccess incluso já ativa compressão e cache.

💡 Dica: certifique-se de que seu site tem SSL (HTTPS) ativo (Let's Encrypt gratuito no cPanel: SSL/TLS Status → AutoSSL). Sem HTTPS, o login social real não funciona.

Capítulo 05 · Login real

Configurar Login do Google

Permita que usuários entrem com o Google de verdade.

1

Acesse https://console.cloud.google.com e faça login com uma conta Google. Clique no menu de projetos no topo → Novo Projeto. Nomeie NEXVON → Criar.

2

No menu lateral: APIs e Serviços → Credenciais. Clique em Criar credenciais → ID do cliente OAuth.

+ Criar credenciais ▾
ID do cliente OAuth
3

Tipo de aplicativo: Aplicativo da Web. Nome: NEXVON Login.

Em Origens JavaScript autorizadas, clique em + Adicionar URI e cole a URL do seu site (ex: https://nexvon-fluencia.netlify.app — sem barra no final).

Origens JavaScript autorizadas:
URI 1: https://nexvon-fluencia.netlify.app + Adicionar URI
Criar
4

Copie o Client ID gerado (formato: 123456789-abc.apps.googleusercontent.com).

5

No seu site NEXVON (tela de login), clique em "Configurar login real (Google/Facebook)", cole o Client ID no campo do Google e salve. Recarregue a página — o botão Google agora usa login real!

⚠️ A URL deve ser exatamente igual (incluindo https:// e sem barra final). Se mudar o domínio depois, volte aqui e adicione a nova URL.

Capítulo 06 · Login real

Configurar Login do Facebook

1

Acesse https://developers.facebook.com e faça login. Clique em Meus Apps → Criar App. Tipo: Consumidor. Nome: NEXVON → Criar App.

2

No painel do app, role até Facebook Login e clique em Configurar. Escolha Web. Cole a URL do seu site → Salvar.

URL do site: https://nexvon-fluencia.netlify.app
Salvar
3

Vá em Configurações → Básico. Copie o App ID (número, ex: 123456789012345). Em Domínios do App, adicione seu domínio (ex: nexvon-fluencia.netlify.app) → Salvar alterações.

4

No seu site NEXVON, clique em "Configurar login real (Google/Facebook)", cole o App ID no campo do Facebook e salve. Recarregue — login do Facebook ativo!

💡 Enquanto o app do Facebook está em modo desenvolvimento, só você (admin) consegue logar. Para liberar para todos, vá em Revisão de Permissões e Recursos e solicite Advanced Access para email e public_profile (geralmente aprovado em poucos dias).

Capítulos 07 e 08 · Finalização

Pós-deploy & Checklist Final

Segurança — troque a senha do admin

1

Faça login com admin@nexvon.ai / admin2100.

2

Clique no botão de Conta (ícone de pessoa no topo) → Alterar Senha. Defina uma senha forte.

⚠️ A senha padrão admin2100 está documentada — troque IMEDIATAMENTE após subir o site.

Testes rápidos (2 minutos)

Abrir o site em celular e computador (responsivo)
Fazer um cadastro de teste (deve ficar pendente)
Logar como admin e liberar o usuário de teste
Testar o sino de notificações e o leitor de voz
Trocar o idioma no seletor (aguardar tradução)
Testar o botão "Acesso ao Sistema" (abre o Language Reactor)
Exportar um PDF de teste no painel admin
Testar login Google (se configurado)

Checklist final de lançamento

Site online com HTTPS (cadeado verde)
Senha do admin alterada
Google Client ID configurado (opcional)
Facebook App ID configurado (opcional)
Domínio personalizado conectado (opcional)
Guia salvo em PDF para a equipe
